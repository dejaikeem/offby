# Offby

**LLM 배치 잡의 예보 심판.**

돌리기 전에 한 문장으로 예상을 적는다. Offby는 그 문장을 측정 가능한 항 다섯 개로 바꾸고, OpenAI 호환 프록시로 잡을 지켜보다가, 숫자가 네 말과 어긋나면 **열 번째 호출쯤에서 잡을 세우고 어느 가정이 틀렸는지 이름을 붙여** 돌려준다. 예산이 다 나간 뒤가 아니라.

> **상태: 설계 → 구현.** Nebius × NVIDIA Global AI Hackathon 출품(마감 2026-10-30). 이 README가 계약이고 코드는 매주 붙는다. 로드맵 체크박스가 켜지기 전엔 아무것도 배송된 게 아니다.

## 문제를 표 하나로

예산 캡은 돈을 센다. 돈은 가장 늦게 움직이는 숫자다.

슬랙에 이렇게 썼다: *"오늘 밤 nemotron-nano로 20만 행 분류, 짧은 프롬프트, 문단 답변, 20달러 안."* 출력은 콜당 ~250토큰이라고 가정한 셈이다. 모델이 답하기 전에 생각(reasoning)을 하니 실제로는 ~2,150 — 가정의 8.6배.

| | 멈추는 콜 | 나간 돈 | 알게 되는 것 |
|---|---|---|---|
| 예산 캡, 가격표에 없는 모델 | 안 멈춤 (200,000) | ~$107 | 없음 — 비용이 $0로 기록됨 |
| 예산 캡, 단가 등록, 캡 $20 | ~37,000 | $20 | "Current cost: 20.0, Max budget: 20" |
| **Offby** | **10** (25에서 정지) | **~$0.01** | "`output_tokens` 예보의 8.6배 · completion 토큰의 87%가 reasoning · think-on이 기본 → `enable_thinking: false`면 $18.9" |

수치는 예시. 단가는 Nebius Token Factory에 게시된 Nemotron-3-Nano 기준.

## 동작

1. **한 문장 → 다섯 항.** `nemotron-3-nano-30b`가 `호출수 · 입력 tok/콜 · 출력 tok/콜 · 단가 · 창`으로 파싱. 안 적은 항은 `ASSUMED` 배지. 단가는 `GET /v1/models?verbose=true`에서 라이브, 모르는 모델은 `UNPRICED`로 최상단에 — 절대 $0 아님. 집행 전에 다섯 항을 확인받는다.
2. **잡을 Offby로 향하게.** 환경변수 한 줄: `OPENAI_BASE_URL=http://localhost:8402/j/<job>/v1`.
3. **10콜부터 심판.** 항별로 관측률 vs 예보, 총액 투영. 전체 평균과 최근 5콜 평균이 **둘 다** 임계(기본 2배)를 넘어야 이탈 — 긴 답 하나로는 안 죽는다. 이탈 시 잡은 무시 못 하는 진짜 에러를 받는다: `402` + `X-Offby-Halt: output_tokens` + 본문에 깨진 항·배수·재개 명령.
4. **진단은 이탈 때만.** `nemotron-3-super-120b`가 증거 묶음(reasoning 토큰 비중, 재시도·429, 캐시 입력 비중, service tier, 언급 안 한 모델)을 읽고 메커니즘·최상위 unknown-unknown·수정 예보를 스트리밍. `accept`로 그 항만 받아들이거나, 원인을 고쳐 재실행.

**hot path에 모델 호출은 0.** 프록시는 응답에 이미 붙어오는 `usage`만 읽는다. 모델은 잡당 두 번 — 예보 파싱 한 번, 이탈마다 진단 한 번.

## 왜 예산 캡만으로 안 되나

캡은 있어야 한다. Offby는 캡을 대체하지 않고 **옆에 선다.** 캡은 누적 달러로 감지해서 돈이 다 나가야 울리고, 메시지는 "현재 지출 vs 한도"만 말한다(2026-09-06 LiteLLM 문서·소스 확인: 선호출 누적 지출 검사, 최신 버전은 낙관적 예약, `soft_budget`은 알럿만, 번들 가격표에 Nemotron 3 없음 → 비용 `None`). Offby는 캡이 구조적으로 못 하는 부분 — **일찍 멈추고, 어느 가정이 틀렸는지 말하는 것** — 만 한다. 이미 게이트웨이를 쓰는 팀을 위해 LiteLLM 플러그인 모드(`CustomLogger` pre-call hook)가 로드맵에 있다.

## 설계 규칙

- **usage만 저장.** 프롬프트·응답 본문은 절대 기록하지 않는다.
- **$0 금지.** 가격 모르면 `UNPRICED`로 첫 줄에.
- **가정은 보이게, 확인받고 집행.**
- **10콜 전엔 판정 없음, 두 평균이 일치해야 이탈.**
- **Offby의 402 ≠ 업스트림 402.** Token Factory 잔액 소진 402와 헤더·`type`으로 구분.
- **`--fail-open`.** 미터가 죽어도 건강한 잡을 죽이지 않는다.
- **reasoning 토큰은 관측 전엔 미지수.** `completion_tokens_details`가 null이면 `reasoning_content`·`<think>` 태그로 추정하고 추정이라 표시. null을 0으로 강제하지 않는다.
